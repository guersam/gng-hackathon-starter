# 기능 추적표

기준일: 2026-08-13

| 기능 | 도메인 핵심 | 런타임 경계 | 사용자에게 보이는 증거 | 자동 검증 |
|---|---|---|---|---|
| 입장과 시작 | 정원·준비·시작 방식 | 권한 인증과 세션별 객체 | 자리 상태와 5초 카운트다운 | 혼합 정원, 중복 준비, 전체 30명 |
| 9초 의무 | 절대 구간 번호와 개인별 충족 | 가장 가까운 마감 알람 | 현재 요일, 남은 시간, 동료 상태 | 경계·중복·오입력·여러 구간 복구 |
| 날짜 문제 | 결정적 날짜 표본과 정수 점수 | 시작·답·시간 초과 명령 | 범위·제한시간·날짜·결과 | 윤년·세기·범위 끝·모든 점수 조합 |
| 실시간 순위 | 원점수와 확정 인원 정규화 | 변화 때만 방송 | 팀별 점수·1인당 점수·공동 순위 | 음수·동점·재생 일치 |
| 연결 복구 | 명령 멱등성과 사건 접기 | 최대 절전 소켓·스냅샷 | 재연결·오래된 화면 상태 | 새로고침·중단·동시 명령 |
| 종료와 성찰 | 사건에서 관찰값 투영 | JSON 내보내기·24시간 수명 | 타임라인과 근거 질문 | 동일 로그의 동일 투영, 진단 문구 금지 |
| 혼자 사전 연습 | `solo_practice`와 한 자리 법칙 | 원자적 생성·개인 권한·같은 DO | 2분 시작, 개인 기록, 준비 확인 | 불법 프로필, 명령 권한, 320px 브라우저 흐름 |
| 기준 게임 개조 또는 새 팩 추가 | manifest·결정·접기·투영 | 호스트와 게임의 import 경계 | `/yoil` 또는 `/handoff` 플레이→변경→재플레이 | 정의 계약, 경계 검사, 예제 게임 테스트 |
| 코더 한 명/팀 전원 | 경험·규칙·플레이·피날레 패킷 | 외부 갤러리·투표는 경계 밖 | 5분마다 전원이 플레이 | 첫 입력 시각과 반복 플레이 기록 |
| 30명 피날레 | 게임별 `finalePlan` | 같은 URL/방 URL/순차 턴 중 선언 | 1분 설명과 복구법 | 행사 전 30명 리허설 또는 명시적 수동 증거 |

이 표는 화면 기능 목록이 아니다. 각 행은 하나의 사용자 사건이 입력부터 저장, 방송, 복구와 검증까지 끊기지 않는지를 확인한다.
