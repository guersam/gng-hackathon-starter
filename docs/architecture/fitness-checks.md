# 적합성 검사

기준일: 2026-08-13

| 품질 | 값싼 상시 검사 | 배포 전 관문 | 남길 증거 |
|---|---|---|---|
| 규칙 정확성 | 타입 검사와 도메인 단위·속성 테스트 | 모든 점수표·날짜 경계·사건 재생 | 테스트 결과 |
| 서버 권위 | Worker 통합 테스트 | 마감 경계와 동시 명령 반복 | 원시 사건과 최종 스냅샷 |
| 복구성 | 스냅샷 재생 테스트 | 최대 절전·새로고침·네트워크 단절 | 복구 전후 사건 번호 |
| 30명 수용 | 짧은 다중 클라이언트 검사 | 최악 조합의 배포 리허설 | 지연 백분위, 오류, 유실·중복 수 |
| 사전 배포성 | 설치·빌드·상태 점검 | 새 무료 계정의 처음부터 끝 배포 | 날짜, 버전, 공개 상태 주소 |
| 혼자 연습 | 도메인·Worker 프로필 검사 | 320px 실제 브라우저의 생성·시작·복구 | Playwright trace와 개인 사건 기록 |
| 모바일 접근성 | 정적 접근성·레이아웃 검사 | 실제 휴대전화, 키보드, 모션 축소 | 화면 캡처와 점검표 |
| 성찰 안전성 | 투영 스냅샷 검사 | 기록 문구 자체 검토 | 진단 없는 세 질문과 타임라인 |

배포 리허설의 행동-방송 지연 목표는 p95 500ms 미만이다. 이는 Cloudflare의 서비스 보장이 아니라 이 프로젝트가 해당 행사 환경에서 측정해 통과해야 하는 기준이다. 중복 정산과 커밋 사건 유실 허용치는 0이다.

`pnpm check`가 상시 관문, `pnpm check:release`가 브라우저 포함 릴리스 관문이며 `pnpm smoke -- <배포 주소>`와 `pnpm load -- <배포 주소>`가 배포 관문이다. `pnpm check:boundaries`는 범용 커널→게임/플랫폼 및 게임→호스트 역의존을 막는다. 실제 스크립트가 이 문서와 달라지면 문서를 완화하지 말고 둘 중 하나를 즉시 일치시킨다.

로컬에서는 `pnpm test:browser:visual`이 선택 화면·두 게임 경로와 두 테마를 320px·1280px로 렌더링하고, `pnpm test:browser:scale`이 30개 독립 브라우저 컨텍스트의 WebSocket 인증을 확인하며, `pnpm test:browser:full`이 120초 서버 종료와 사건 증거를 확인한다. 이것은 배포 제공량·지연·두 방 Wi-Fi를 닫는 증거가 아니다.
