# 상속 요소와 호환성 자유

기준일: 2026-08-13

## 유지해야 할 힘

- 휴대전화 링크로 빠르게 방에 들어가는 경험
- 점수와 마감에 대한 서버 권위
- 동시 입력이 있어도 결과가 한 번만 정산되는 성질
- 사건 기록을 다시 접어 결과를 설명하는 능력
- 배포 상태를 참가자가 직접 확인하는 경로

이 항목들은 기존 구현을 복사하라는 뜻이 아니다. 각각 새 도메인 규칙, Durable Object 경계와 자동 검사로 다시 증명한다.

## 호환성을 요구하지 않는 것

- 이전 방, 저장 데이터, 링크, 브라우저 저장 키와 배포 주소
- 이전 프로토콜, 화면 구조, 컴포넌트 API, 환경 변수와 공급자 설정
- 이전 이름, 은유, 규칙, 문구, 패키지와 런타임

새 스키마와 프로토콜은 공개 전 솔로 프로필을 포함한 `yoil-genius:v2`에서 시작하며 이전 데이터 마이그레이션이나 리디렉션을 제공하지 않는다.

## 명시적 은퇴 장부

이 절만 이전 제품을 식별한다. 공개 화면과 다른 문서에는 아래 이름이나 기술을 남기지 않는다.

| 은퇴 대상 | 처리 |
|---|---|
| 관제탑 / `gwanjetap` 이름과 clean-language·은유 게임 | 새 규칙 및 한국어 제품 언어로 전면 교체 |
| Next.js 애플리케이션과 API 라우트 | Vite React 정적 화면과 native Worker로 교체 |
| Redis·Upstash 저장과 Vercel 배포 설정 | 세션별 SQLite Durable Object와 Cloudflare 배포로 교체 |
| 이전 공개 문서, 링크와 브라우저 키 | 삭제하고 `yoil-genius:v2` 계약으로 새로 시작 |

Git 이력은 저작 이력으로 남지만 제품 호환성 표면으로 취급하지 않는다.
